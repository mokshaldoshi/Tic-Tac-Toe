# Tic Tac Toe 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 About the Project

This project is a browser-based implementation of the classic Tic Tac Toe game where two players take turns marking spaces on a 3×3 grid. The first player to get three marks in a row wins!

## ✨ Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Alternating turns between X and O.
- Automatic winner detection.
- Draw detection.
- Reset and restart functionality.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game in your browser.
2. Player X starts the game.
3. Players take turns selecting empty cells.
4. The first player to get three marks horizontally, vertically, or diagonally wins.
5. If all cells are filled without a winner, the game ends in a draw.
6. Restart the game to play again.

## 💻 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/mokshaldoshi/Tic-Tac-Toe
   ```

2. Navigate to the project folder:

   ```bash
   cd Tic-Tac-Toe
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in VS Code.
